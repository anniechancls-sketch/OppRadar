# OppRadar · 商机雷达交互原型（演示）

一个单文件静态交互原型，用于演示「招投标商机自动采集与智能分发」的界面与交互。

## 内容

- `index.html` —— 完整原型（零依赖、无需构建、无外部请求，双击即可打开）。
- 覆盖界面：商机看板、商机列表、认领与跟进、分发规则、数据源管理、五站接力、角色与权限。

## 重要声明

- 页面内**全部为虚构演示数据**，机构名称已做虚构化处理。
- **未接入**任何真实数据源、企业微信、数据库或权限系统；不含任何密钥或凭据。
- 这是**演示原型，未通过验收**，不代表任何真实业务系统，也不构成任何业务承诺。

## 本地预览

直接用浏览器打开 `index.html`。

## 部署

静态站点，入口为仓库根目录的 `index.html`，可直接由 Vercel / Cloudflare Pages / GitHub Pages 托管。
