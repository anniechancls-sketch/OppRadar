关于本原型

本页对应界面规格；原型为演示版本，未通过验收。

它是什么 / 不是什么

是什么
界面与交互评审用的高保真原型，采用 Element UI 风格，覆盖看板、列表、认领、跟进、规则、数据源、五站接力、权限八个界面。
不是什么
不是可运行系统：没有后端、数据库、真实采集、企微推送、权限校验；数字为演示数据。
技术说明
单文件、无外部依赖、离线可打开；仅用原生 HTML/CSS/JS 模拟 Element Plus 视觉与组件行为。
证据声明
截图或演示均不能作为业务验收证据；业务用例全部 NOT_RUN。
